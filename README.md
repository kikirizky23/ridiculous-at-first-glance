One-sentence startup pitch for make.fun's "Ridiculous at First Glance, Real by the Second" bounty: "We hire retired magicians as forensic accountants, because nobody finds hidden money faster than people trained to make it disappear." The program writes that single sentence to `/output/entry.txt` — one sentence, 133 characters. The pitch sounds like a joke until the second clause reframes it: the people best at making money vanish are the ones best at noticing where it went, which is exactly what a company pays a forensic accountant to do.

## Run it

```sh
node main.ts
```

It creates the output directory if needed, writes `/output/entry.txt` as UTF-8 (one sentence, 133 characters, no trailing newline), and reads the file back to confirm it matches the pitch exactly.
